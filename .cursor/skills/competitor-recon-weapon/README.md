# competitor-recon-weapon

The procedural arsenal for `competitor-recon-guardian`, the evidence-first competitor and product teardown specialist. It encodes how to capture what a competitor product actually does (authenticated UI walkthroughs, public-artifact archaeology, client-bundle mining), how to verify findings across account states before recording them, and how to synthesize the evidence into a per-surface gap analysis with a phased build-order recommendation.

The method is generalized from a real hand-run teardown (Assistable vs the cuantico-sms portal, 2026-07-02) captured in the Command Brief at [`ai-tools/command-briefs/competitor-recon-guardian-command-brief.md`](../../command-briefs/competitor-recon-guardian-command-brief.md) and the primary sources gathered in [`research/research-summary.md`](research/research-summary.md).

This weapon does NOT render strategy verdicts (that is white-council-guardian), author PRDs (library-guardian), or run forensic/legal investigations (code-forensics-guardian). It gathers evidence, ranks gaps, and routes.
