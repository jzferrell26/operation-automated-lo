# Reports

This folder accumulates the config audits this weapon produces over time, one file per run.

- Audit reports are generated from `../templates/config-audit-report.md` per `../guides/08-config-audit.md`.
- Naming: `<YYYY-MM-DD>-<app-slug>-config-audit.md`.
- These are historical records. Do not edit a past report; produce a new dated one for a re-audit.
