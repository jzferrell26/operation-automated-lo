# reports/

This folder collects the teardown reports competitor-recon-guardian produces over time. It starts empty.

Each teardown produces a gap-analysis report (authored from `templates/gap-analysis-template.md`) that normally lives in the CONSUMING project's knowledge base (e.g., `library/knowledge-base/ux-ui/<target>-parity-gap-analysis.md`), alongside its paired reference-screenshot corpus. When a report is retained here as a Guild-level example or reference, name it `<YYYY-MM-DD>-<target>-parity-gap-analysis.md`.

Reports are dated. Competitive analysis is a recurring activity: a target re-teardown produces a new dated report rather than overwriting the old one, so the drift over time is auditable.

Reports never contain: verbatim competitor prose, un-redacted PII, or a strategy verdict (that is white-council-guardian's, routed per Hard Rule 7).
