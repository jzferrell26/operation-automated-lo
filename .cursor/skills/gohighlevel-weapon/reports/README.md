# reports/

Where `gohighlevel-guardian` accumulates audit / investigation reports (e.g. a write-back
failure post-mortem, a custom-field drift audit, a rate-limit incident review).

Naming: `YYYY-MM-DD-<short-topic>.md`. Each report states the symptom, the GHL call(s) involved,
the root cause, the fix, and whether the 3-runtime transform lockstep was affected.
