# Reports

This folder collects past `live-latency-guardian` diagnosis runs over time, using the shape in `templates/diagnosis-report-template.md`. Each run should be saved with a dated filename (e.g. `2026-07-15-agents-cuantico-us-diagnosis.md`) so a history of diagnosed apps and their fix outcomes accumulates for future reference. The folder is empty at forge time; the first entry is written the first time this weapon runs against a real target.
