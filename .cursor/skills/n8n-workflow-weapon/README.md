# n8n-workflow-weapon

The Weapon wielded by `n8n-workflow-guardian`: the build/audit/safe-edit toolkit for n8n workflows across the three surfaces Cuantico actually uses (the instance-native n8n MCP server, the public REST API, and the Workflow SDK). It encodes the disciplines that keep a live client workflow from breaking silently: credential-binding integrity, the draft-vs-publish version model, allowed-key PUT payload hygiene, node-by-node validation, error-handling mechanics, idempotency, and the n8n Data Table surface. It owns build/audit/safe-edit MECHANICS only; enrichment-loop design, GHL field semantics, live-event run ops, and security catalogs route to their own Guardians.

Built by `weapon-forge` (Phase 2) from the Command Brief at `ai-tools/command-briefs/n8n-workflow-guardian-command-brief.md` and the research synthesized in `research/research-summary.md`. The `research/` folder is the audit trail authored by `loremaster` and is read-only to this Weapon.

Start at `SKILL.md`. It is the navigation layer that points to the numbered `guides/`, the worked `examples/`, the fill-in `templates/`, and the report shape in `reports/`.
