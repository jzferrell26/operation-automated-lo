# email-marketing-weapon

This is the Cursor skill that equips `email-marketing-guardian` to design and audit deliverability-first email campaigns and write high-converting copy across cold and warm sends for any client, per the [email-marketing Command Brief](../../command-briefs/email-marketing-guardian-command-brief.md). It encodes the 2026 inbox-placement rulebook (authentication, monitoring, list hygiene, spam-filter HTML), the GoHighLevel / LeadConnector sending runbook, launch-sequence and copy frameworks, and a pluggable per-client brand-voice pack format, all built from the loremaster sweep summarized in [research/research-summary.md](./research/research-summary.md). Deliverability is the non-negotiable gate that must clear before any copy ships; start at [SKILL.md](./SKILL.md), which routes each request type into the numbered guides under `guides/`.
