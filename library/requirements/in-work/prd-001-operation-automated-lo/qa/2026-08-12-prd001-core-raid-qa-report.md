- [ ] **Paid-ad raster rendering cannot render or cover-crop approved imagery (001D-AC-021)** - `packages/rendering/src/paid-ad-render-sources.ts:62-68`, `packages/rendering/src/playwright-browser.ts:53-55`, `packages/rendering/src/playwright-browser.ts:192-200`

  The paid-ad source converts property and lender identity asset references into inert `data-*` attributes. Its HTML contains no image element, focal point, cover-crop geometry, or safe-zone geometry. The browser adapter then passes `undefined` instead of an asset manifest for every `paid_ad` job, so any paid-ad asset request would be blocked even if markup were added. This contradicts 001D-AC-021, "Images are cover-cropped with configurable focal point and safe text zones," and makes the current ledger VERIFIED claim incorrect.
