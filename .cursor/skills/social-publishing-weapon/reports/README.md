# reports/

This folder collects the outputs `social-publishing-guardian` produces over time: publish-run hand-off reports and audit findings. Each run writes a dated file (e.g. `2026-07-08-ghl-hfbomb-push.md`) using the shape in `REPORT-TEMPLATE.md`.

- A PUSH RESULT report lists what landed (every post a verified draft), where the human reviews and publishes it, and any failure with its exact API error.
- An AUDIT report lists severity-ranked findings (each quoting the exact API error) for a broken or risky existing setup.

No em dashes in any report. Quote API errors verbatim. Never include a token.
